Measured vs. estimated: the MH370 search

Between 2014 and 2017 the search for flight MH370 mapped a 120,000 km² swath of this remote seafloor in detail. Turn on “What's actually measured” to see that swath against surroundings that are only estimated from satellite gravity.

Explore Measured vs. estimated: the MH370 search in 3D

Where it is

Measured vs. estimated: the MH370 search is centred near 36.00° S, 93.00° E. In the 3D globe you can turn on What's actually measured to see which parts of this seafloor were surveyed by ships and which are only estimated from satellite gravity, draw a depth profile across it, or change the sea level.

About the data

Depths come from the GEBCO 2026 global grid (15 arc-seconds, about 460 m at the equator). Across the whole ocean, 30.8 % of the seafloor is directly measured; the rest is estimated. Read how this is computed.
